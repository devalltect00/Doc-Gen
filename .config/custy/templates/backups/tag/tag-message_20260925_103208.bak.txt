✨ Doc Gen v1.1.0 — Project-Aware Structure Documentation

Doc Gen v1.1.0 adds composable project detection and documentation metadata for
repositories that combine multiple languages, frameworks, and development
tools.

### Highlights

- Detect Python, Django, Flask, FastAPI, Node.js, React, Next.js, Google Apps
  Script, PHP, Laravel, Go, and Gin projects.
- Combine ecosystem, framework, and tool context instead of forcing every
  repository into one isolated metadata set.
- Generate descriptions for recognized files and directories that actually
  exist in the selected project.
- Support explicit project-type overrides when automatic detection needs help.
- Apply project-aware ignore rules before repository scanning.
- Use `docs/project_structure.md` consistently as the default output, including
  before project configuration is initialized.
- Preserve custom output paths while producing formatter-friendly Markdown
  with stable line endings, clean trailing whitespace, and one final newline.

### Safety

- Detection remains read-only.
- Local clasp configuration and environment files that may contain identifiers
  or credentials are not read or included in generated trees.
- Dry-run behavior and output-write boundaries are unchanged.
- Common whitespace-oriented pre-commit hooks should accept generated output
  without rewriting it; project-specific formatters remain under user control.

### Compatibility

Existing commands, profiles, configuration precedence, and explicit output
selection remain compatible. Python 3.9+ is supported.
